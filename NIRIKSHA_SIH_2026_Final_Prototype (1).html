About NIRIKSHA

Smart inspection assistant — SIH 2026 prototype.

Problem → Solution

NIRIKSHA is a prototype software system for scanning packaged commodity labels, extracting declarations, running configurable Legal Metrology checks and producing an evidence-oriented inspection report.

AI layer

OCR extracts visible text from the uploaded image. Keyword/entity patterns classify likely manufacturer, product name, quantity, MRP, date and consumer-care declarations.

Compliance layer

A transparent rule engine converts each detected declaration into PASS, FAIL or REVIEW with a reason. This makes the result explainable to an inspector.

Prototype architecture

Image → OCR / Vision Model → Declaration Extraction ↓ Rule Engine / Validator ↓ PASS • FAIL • REVIEW ↓ Evidence + History + PDF Report
